**2. New findings**

1. **MEDIUM · Valid key characters are deleted before detection**  
   **Location:** `scripts/secret-scan.sh:199–207`, applied at `:355–360`. **Inside the change range.**

   The new `XRUN` substitution deletes every run of four or more uppercase X characters, including characters inside a valid-format key. This can shorten the value below its detection rule’s required length.

   **Failure scenario:** a developer commits an AWS-shaped identifier or an OpenAI-shaped key containing such a run. The installed gate approves its publication.

   **Evidence:** both synthetic cases returned **2** with the scanner from `8ddf452`, but **0** with HEAD’s scanner. After installing HEAD’s hook in throwaway repositories, both actual local pushes succeeded, printed scanner success, and advanced the receiving ref. An AWS control of the same length without the X run blocked and left the receiving ref unchanged. These were synthetic values; none is reproduced here.

   The header’s claim that rejoining the remainder preserves detection is therefore wrong for length-dependent rules. This is not merely acceptance of a placeholder.

2. **LOW · The new guard suite fails during remote-name setup on the installed Git**
