Install

Three steps, no rebuild

Works on any page that can include a script tag — a hand-written site, a CMS theme, a site-builder's custom-HTML block. No account, no framework, no build step.

  1. Copy the line

    One script tag is the whole install — use the copy button below.

  2. Paste it before </body>

    At the end of your page's HTML, just above the closing </body> tag — on every page where you want the assistant.

  3. Done

    The “Book by text” pill appears bottom-right. Your pages, styles and scripts are left completely untouched.

S2CSS isolation

The widget lives in a Shadow DOM with an all:initial root: the host's fonts, colors, resets and even same-named classes (.chip, .panel, .launcher…) cannot reach in — and no widget style leaks out. The live demo page attacks it with seven hostile-CSS scenarios, including real class collisions, and the widget stays pixel-true.

Proof: host-demo.html — its “integration note” card is a leak canary. Decision + rejected alternatives (iframe, namespace) recorded in ARCH-DEC.
