Availability rejections

SCREEN-INVENTORY §2.4 · W14–W18

All five are engine literals — no messageTemplates key exists for them. They stay conversational (plain bot bubble, stage returns to collecting): a rejection is a normal turn, not an error. Fail-closed: the rejected slot is wiped from state, so a stray “yes” after any of these cannot book the refused time.

W14Taken — alternatives
Friday 4 Sep 15:30 is taken. Free that day: 10:00, 10:30, 15:00. Which works? 10:00 10:30 15:00 14:02

The engine sends plain text; rendering the ≤3 alternatives as tappable chips is frontend work — the engine is unchanged.
