The stage machine behind every bubble

Nine stages govern which reply is even possible. handoff is a lock — no customer path leads out; only the owner releases it (the dashboard's single write action).

new ──▶ collecting ──▶ ready ──▶ confirming ──▶ booked
 │           ▲ (slot rejected — fail-closed)      │
 ├──▶ cancel_confirming ──▶ cancelled | new
 ├──▶ reschedule_confirming ──▶ booked | new
 └──▶ handoff  ⛔ LOCK — no customer exit (owner only)
